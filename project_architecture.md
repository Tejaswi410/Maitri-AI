# 🌌 Maitri AI: Project Overview & Architecture

**Maitri AI** is an advanced, voice-interactive AI assistant designed to provide personalized mental health support contexts, originally conceptualized for astronauts on long missions but broadly applicable. The system listens to user audio, understands their emotional state, remembers past context, generates empathetic responses, and speaks back using highly realistic, dynamically selectable cloned voices.

The project was specifically re-architected to leverage extremely fast Cloud APIs and Hugging Face infrastructure to bypass heavy local C++ compilation requirements, making it highly portable and performant.

---

## 🛠️ Technology Stack & Models Used

### 1. Speech-to-Text (STT) Transcripton
* **Model Used:** `whisper-large-v3` (OpenAI's state-of-the-art open-source Whisper model)
* **API Provider:** **Groq API**
* **Implementation:** [pipeline/stt.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/stt.py)
* **How it works:** When a user records or uploads audio, the file is sent to the Groq API. Groq utilizes specialized LPU (Language Processing Unit) hardware to transcribe the audio into text almost instantaneously with incredibly high accuracy.

### 2. Emotion Detection
* **Model Used:** `j-hartmann/emotion-english-distilroberta-base` (Fine-tuned DistilRoBERTa)
* **Provider:** Hugging Face `transformers` library (Executed Locally)
* **Implementation:** [pipeline/emotion.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/emotion.py)
* **How it works:** The transcribed text is passed through this lightweight NLP model, which classifies the user's emotional state into one of several categories (e.g., joy, sadness, anger, fear, surprise, disgust, neutral). This emotion is heavily weighted when generating the final response.

### 3. Memory & Context (RAG Pipeline)
* **Model Used:** `sentence-transformers/all-MiniLM-L6-v2` for generating embeddings.
* **Database:** **FAISS** (Facebook AI Similarity Search - CPU version)
* **Implementation:** [pipeline/memory.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/memory.py)
* **How it works:** This is a Retrieval-Augmented Generation (RAG) system. Past notes, context, or conversations regarding the specific user (identified as `ASTRO_001` in the system) are embedded into high-dimensional vectors. When the user speaks, their current text is also embedded, and FAISS performs a semantic similarity search to pull up the most relevant past memories to ground the AI's response in reality.

### 4. Large Language Model (LLM) Generation
* **Model Used:** `llama-3.1-8b-instant` (Meta's Llama 3.1)
* **API Provider:** **Groq API**
* **Implementation:** [pipeline/llm.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/llm.py)
* **How it works:** The LLM receives a highly structured prompt containing the transcribed text, the detected emotion, and the retrieved memory context. It acts as an empathetic mental health counselor, generating a thoughtful, personalized text response tailored specifically to the user's current situation and emotional state.

### 5. Dynamic Voice Cloning (TTS)
* **Model Used:** **F5-TTS** (A highly realistic zero-shot voice cloning model)
* **API Provider:** **Hugging Face Spaces** (via `gradio_client`)
* **Implementation:** [pipeline/voice.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/voice.py)
* **How it works:** F5-TTS requires a ~10-second reference audio clip and the exact textual transcript of that clip. It takes the text generated by the LLM and synthesizes it flawlessly using the vocal profile of the reference audio. 
* **Profiles Setup:** We extracted, cropped, and transcribed customized reference clips so the user can instantly clone specific voices dynamically:
  * Narendra Modi
  * Andrew Tate
  * Donald Trump
  * Virat Kohli
* **Robustness & Fallbacks:** Because Hugging Face ZeroGPU spaces have strict rate limits, the pipeline authenticates with a personal `HF_TOKEN` and implements an automated fallback loop (`mrfakename/E2-F5-TTS`, `Innovert/F5-TTS-Space`, etc.). If one server fails, it seamlessly tries the next.

### 6. Web UI & Deployment
* **Framework:** **Gradio**
* **Implementation:** [app.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/app.py)
* **How it works:** Gradio wires all 5 pipeline components together into a single, cohesive, interactive web interface. It natively handles microphone browser permissions, audio file uploads, and dropdown states for voice selection, presenting the entire product beautifully with a premium theme.

## 🔄 The Execution Pipeline (Step-by-Step)

When a user interacts with the app, the [process_interaction()](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/app.py#20-44) function in [app.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/app.py) orchestrates the exact flow:

1. **Input:** The user speaks into the microphone (or uploads a [.wav](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/voice_cloning/voice_profiles/ASTRO_001/ref_cropped.wav)/`.mp3` file). They select a Voice Profile from the dropdown menu.
2. **Transcription ([stt.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/stt.py)):** The audio file is instantly transcribed into text via Groq Whisper.
3. **Analysis ([emotion.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/emotion.py)):** The text is scanned to detect the underlying emotional sentiment.
4. **Context ([memory.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/memory.py)):** The text is embedded, and FAISS retrieves relevant context about the ASTRO_001 user.
5. **Generation ([llm.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/pipeline/llm.py)):** The LLM synthesizes the transcription, emotion, and memories to write a supportive response text.
6. **Vocalization ([voice.py](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/setup_voice.py)):** The response text, combined with the Voice Profile's reference audio/text, is sent to the F5-TTS API, which returns a [.wav](file:///c:/Users/Shivam%20Gupta/OneDrive/Desktop/Tejaswi/Maitri%20AI/voice_cloning/voice_profiles/ASTRO_001/ref_cropped.wav) file of the cloned voice speaking the response.
7. **Output (Gradio UI):** The user interface displays the Input Text, Emotion, Output Text, and automatically plays the newly generated audio response.
